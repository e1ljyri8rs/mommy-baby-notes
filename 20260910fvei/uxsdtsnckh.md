# 美国医院有没有人造子宫可以用来生孩子？

> 更新时间：2026-09-10 (UTC+8)

目前并没有美国医院可以用人造子宫生育孩子，因为该项技术还未研发成功。如果之后研发出的人造子宫，可以百分百模拟正常子宫生育的环境，则可以代替人类生育。但是目前的科学设备以及医疗水平，人造子宫并不不能够达到正常子宫子宫的条件，而且也没有人造子宫生育孩子的先例，这暂时只是科学家的想法。人造子宫是理想中的科研及繁衍装置，它通过模拟哺乳动物子宫和卵生动物卵的条件，使受精卵在人造环境下发育，从而摆脱对母体的需求。
人造子宫现在还只是科学家的一个实验项目，现在还处于试验阶段，是一种对未来的设想，在世界范围内这项技术都还没有用于临床辅助生殖，而且就算有人造子宫，人造子宫是可以孕育生命的，但是用人造子宫培育人类胎儿还难保安全，存在一定的风险。

## 人造子宫发展

关于人造子宫的设想，早在1924年，英国遗传学家哈尔登就预言，到2074年，将有七成的婴儿通过体外孕育并诞生，这是关于体外培育的最早设想。

- 1. 1923年霍尔丹在剑桥大学邪学社（Heretics Society）举行的一次讲座中首次对人造子宫进行深入探讨后，各国科学家就一直在致力于研究胚胎脱离母体生长的可能性；
- 2. 1969年，法国科学家首先将早产羊置于人工子宫内培育，羊羔存活了两天；
- 3. 1992年，东京大学研究人员利用人工子宫诞生下一个羊羔；
- 4. 2017年，美国费城儿童医院的研究人员，将早产的羊羔放置在人工子宫内继续培育，其后又进行剖腹产，小羊发育良好；
- 5. 2018年，荷兰设计周期间，科研人员邀请艺术家们打造了人工子宫的模型，还注明了详细的工作原理。研究人员的计划是，在2025年之前完成相关的试验，然后开启临床上的应用。

按照研究人员的设想，人造子宫内要具备类似羊水的液体，还要具备能够正常运转的血液循环系统。但这却困难重重，并且用人造子宫生育孩子将会面临事实上的“无父”或者“无母”的状态，这些伦理上的模糊地带和未知领域，都亟待去填充和赋予新的伦理程序。
