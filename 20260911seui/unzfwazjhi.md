# 乳腺结节都是气出来的？如何自检？来听听专家的解答

> 更新时间：2026-09-11 (UTC+8)

**Q: 夏天贴乳贴会影响乳房健康吗？**

郑立平：一般来说是不会的，乳贴和内衣一样，算贴身的物品。目前市面上大多数在设计时会选择分区，乳头部分会使用更柔软、透气、皮肤友好的材质，如纤维素材料、硅胶、聚酯薄膜等，避免对乳头产生刺激或不适感。周围的材质则需要更具粘性和牢固性的材质，如医用胶水、胶带材料、聚酯薄膜、硅胶边缘等，以确保乳贴在皮肤上牢固粘附的同时也不会产生刺激感。只要产品符合国家安全规范，大家正常使用即可。但是我们的皮肤是需要呼吸的，乳房也不例外，再次还是建议大家不要长期使用乳贴，使用6个小时左右需要及时更换，避免使用不当引起湿疹等皮肤问题。

**Q: 日常总是感到胸闷胸胀，需要到医院做彩超检查吗？有必要加做钼靶检查吗？**

郑立平：建议到医院进行彩超检查，明确病因。但是否需要加做钼靶检查，因人而异。乳房的钼靶检查其实就是x线检查，这种检查具有一定的伤害性，不能作为常规的检查。是否需要做检查，我们还需要做年龄段的区分，40岁以上的女性、乳房较大、有家族史，或者是彩超检查提示有问题的，这几类情况我们才建议追加做钼靶检查。如果乳腺检查没有问题，我们建议2-3年再进行复查。50岁以上的高龄年龄段，建议每年进行1次钼靶检查。乳房作为体表器官，彩超检查即可满足一般的检查需求，可以作为首选常规的检查手段，没有什么伤害性，短时间内可以多次检查，建议大家每年定期做1次检查即可。如果乳房已经有结节的人群，可能要半年做1次检查，甚至间隔3个月严密随访。

**Q: 经常喝豆浆、吃乳制品会不会诱发乳腺癌？**

郑立平：豆浆是由黄豆磨制成的，它所产生的雌激素是植物类雌激素，跟我们人类的动物性雌激素是有一定的差别的。总体来讲，每个人都有一些特殊体质，个体化差异。饮用豆浆诱发乳腺问题，我认为是没有根据的，但是在饮食当中，不能过量食用，物极必反。乳腺疾病的发生，主要是由于我们体内雌激素的波动引起的，情绪、熬夜是主要因素，大家保持健康良好的生活作息才是关键。

**Q: 青春期少女发现乳房有肿块需要做检查吗？乳房如何进行自检？**

郑立平：需要，建议到医院进行彩超检查，看看是否是乳腺增生还是乳腺肿块。此外，乳腺纤维瘤这类疾病多见于青春期少女，乳房内出现可移动肿块需要警惕。乳腺纤维瘤是一种良性肿块，不能自行消除，可能会越长越大，建议家长们带孩子积极到医院就医。

此外，乳房自检是非常重要的，我们自身对于身体的部位是非常敏感的。乳房自检的最佳时间在月经来潮后7-10天（月经干净后3-5天）进行，一般不选择在经前或经期进行。自检的方法就是对着镜子站好，完全暴露双侧乳房，双手叉腰或上举双上肢，观察双侧乳房是否对称，双侧乳房轮廓、乳头、乳晕是否有异常；用左手触摸右乳，用右手触摸左乳，以乳头乳晕为中心，顺时针或逆时针，触摸乳房四周及腋下有无肿块，最后轻轻挤压乳头，有无液体溢出；也可以换为仰卧位，一侧上肢上举，另一侧手触摸对侧乳房，同样查看有无肿块及乳头有无溢液。

**Q: 乳房结节和肿块有什么区别？乳房结节都会癌变吗？**

郑立平：乳房肿块其实是一个统称，但是我们会把小于3公分的肿块称为结节，超过 3公分的叫肿块，因为体积比较大。肿块/结节无论大小，从狭义上来讲，主要还是区分良性或者恶性。但是高龄女性要注意，若是年轻时在体内发现良性结节，绝经后结节还在增大，大家需要提高警惕。乳房疾病是受雌激素控制的，绝经后卵巢功能衰退，在几乎没有雌激素的影响下，乳房肿块仍然在存在或增大，恶变的可能性更高。

**Q: 孕15周，乳腺已经开始分泌乳汁，这种现象正常吗？**
郑立平：只要不是血性溢液，并且乳腺彩超检查没有提示病变，大家可不用太过于担心。这种分泌物其实就是初乳，是乳房在分泌乳汁前所分泌的淡黄色液体，是正常的一种生理现象，其实也是孕妈妈身体为迎接新生宝宝的到来，做的哺乳功能排练。孕妈体内的孕激素刺激着乳腺，启动了乳房的分泌机制，让乳房等到宝宝出生后，以便让它实现正常哺乳功能。而且，你的年龄越大，怀孕次数越多，乳房出现一些分泌物的可能性就会越高。但是，孕期乳房没有出现过分泌物的孕妈也别太担心，这并不能说明你不能分泌乳汁，生完孩子后，还是会分泌初乳的。

**Q: 平时比别人怕冷，还总是犯困，是自己的甲状腺出现问题了吗？**

苏亚静：如果有这些症状，可能是体寒、脾虚等等多种原因导致的，同时需要排除是否患有甲状腺问题的。这是由于甲状腺功能的减退，会导致甲状腺激素的减少，进而引起我们体内新陈代谢的转变、减慢，导致大家出现怕冷、嗜睡、做事没有激情的症状。如果大家存在这些情况，建议大家到医院的乳甲外科或者内分泌科进行抽血和彩超检查，查看甲状腺功能是否存在异常。

**Q: 甲状腺如何自检？**

苏亚静：甲状腺自检主要分2步走，第一是看，就是对着镜子查看我们的脖子是否有异常肿大，或者是突发的颈前肿块。第二就是摸，首先找到我们的气管，大拇指和我们的四指分开，按在气管两侧，上下活动查看我们的甲状腺是否有肿块、结节，如果摸到了，再进行一个吞咽动作，观察我们的结节是否会随之活动。如果出现这个现象，那就说明我们的甲状腺可能长结节了。但是请大家注意，有相当多的微小甲状腺癌不能通过自检查出来，还需要借助超声检查才能发现。

**Q: 甲状腺彩超检查提示4a类，穿刺为良性，可以继续观察吗？**

苏亚静：甲状腺癌不同于乳腺癌，是一个懒癌，进展缓慢。若甲状腺彩超检查提示4a类的结节，存在5%左右的恶性可能性，若穿刺结果为良性，应积极进行随访。如果结节的位置长在邻近气管壁或喉返神经及颈鞘大血管附近，就需要警惕，建议积极手术。

**Q: 得了桥本甲状腺炎，脖子有点肿，可以怎么消肿呢？网上建议吃中药、补硒和维生素D，这些可信吗？**

苏亚静：桥本甲状腺炎是一种特殊的炎症，又叫慢性淋巴性甲状腺炎，是我们自身免疫系统性疾病，目前没有明确的病因治疗，只能是对症治疗。如果说甲状腺功能正常，我们定期观察即可。如果说甲状腺出现肿大，并且压迫到我们的器官，我们可以进行短期药物治疗，若还是没有缓解，可能需要进行手术治疗。此外，对于网上吃中药的说法，建议大家前往正规医疗机构的中医科进行咨询。那么硒和维生素D都属于我们体内的微量元素，会参与我们体内内分泌激素的分泌，适当的补充对我们的甲状腺是有好处的。

**Q: 熬夜、工作压力大是否也会影响甲状腺功能？**

苏亚静：甲状腺是我们体内最大的内分泌器官，受许多方面调节，甲状腺激素和促甲状腺激素是有一个昼夜节律的波动性活动的。一般情况下，在午夜凌晨的时候达到高峰，白天的时候达到最低峰。如果长期熬夜，导致内分泌紊乱，甲状腺就容易出现问题。另外，情绪是我们体内最大的一个神经内分泌器官，压力大、情绪异常也容易引起体内皮质醇升高，也会间接影响到我们甲状腺。大家一定要少熬夜哦~
